# ESOP Blockchain Module

Smart contracts for ESOP management on Ethereum blockchain.

## Quick Start
```bash
# Install dependencies
npm install

# Start local blockchain
npm run ganache

# Compile contracts
npm run compile

# Deploy contracts
npm run migrate

# Run tests
npm test

# Interact with contracts
npm run interact
```

## Smart Contracts

- **ESOPManagement.sol**: Main ESOP logic (grants, vesting, exercise)
- **AccessControl.sol**: Role-based permissions (Admin, HR, Employee)
- **Migrations.sol**: Truffle deployment helper
